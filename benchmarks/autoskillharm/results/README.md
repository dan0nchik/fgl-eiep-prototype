# Результаты AutoSkillHarm (свежая генерация на Grok)

Здесь лежат машинно-читаемые сводки прогонов. Подробная история первой атаки,
с текстами инъекций и фрагментами транскрипта — в соседнем каталоге
[`../attack_preview_combo1/`](../attack_preview_combo1/README.md). Журнал всего
цикла (настройка, экономика, все итерации) — [`../RESULTS.md`](../RESULTS.md).

## grok-v3-manifest-summary.json

Сводка прогона **V3** (ночь 19–20 ноября 2026) — выгрузка метаданных из серверных
манифестов без текстов атак и кода:

- **Генерация**: 12 комбинаций (задача, тип вреда) запускалось — манифесты собрали
  4 (16 сценариев = 4 задачи × 4 реализации: plain_text, подмена документа, PDF,
  подмена скрипта). Сканер-фильтр авторов пометил все реализации «safe» —
  то есть дизайнер на Grok обходил сканер штатным циклом статьи (шаг 5.7).
- **Оценка**: 48 попыток жертвы (16 сценариев × 3 условия: без защиты, защита
  авторов, FGL-промпт) — **все сорвались ошибкой соединения**, ASR = null.
  Статус в JSON честно помечен `invalid_connection_errors`: нули — это не
  «атаки не сработали», а «замер не состоялся».

**Почему сорвались.** Жертва — Codex CLI в контейнере Harbor 0.6.3 — получала
имя модели без префикса (`grok-4.7` вместо `x-ai/grok-4.7`): адаптер Harbor
срезал префикс, роутер отвечал «model not found». Найдено по транскриптам,
починено 20 ноября 8:19 UTC (адаптеру предписано передавать имя целиком).
Подробности — RESULTS.md, раздел про фиксы.

**Статус этого файла**: фиксация V3 как была. Валидный перегон оценки по тем же
16 сценариям идёт следом (20 ноября, после фикса) — его цифры заменят null в
следующей выгрузке; суммарная таблица none / authors / fgl ляжет в RESULTS.md.

## Происхождение

Сервер `ithse.ru`, `~/autoskillharm_run`. Пайплайн авторов AutoSkillHarm
(SkillHarm, arXiv 2606.02540) без правок харнесса; проектировщик / жертва /
сканер — x-ai/grok-4.7 через routerai.ru. Полные транскрипты и манифесты
остаются на сервере (в выгрузки не переносятся).
